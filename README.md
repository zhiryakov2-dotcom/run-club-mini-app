## Что умеет приложение

- **Главная** — ближайшая тренировка с кнопкой «Я участвую» и последняя эстафета.
  Под карточкой тренировки — чипы участников: кружок с первой буквой имени
  и имя (у каждого свой цвет).
- **Календарь** — все события с датами, счётчиком и чипами участников,
  кнопка «Я участвую» и форма «+ Добавить тренировку» (нужен пароль админа).
- **Объявления** — доска клуба, кнопка «+ Добавить объявление» (пароль админа).
- **Эстафеты** — архив командных стартов с результатами,
  кнопка «+ Добавить эстафету» (пароль админа).
- **Участники** — карточки членов клуба, кнопка «+ Вступить в клуб»
  (без пароля, имя подставляется из Telegram).

Запись «Я участвую» попадает в таблицу на лист «Записи»
(Участник, Событие, Дата записи, Статус «Иду»), дубли по имени не создаются.
Кто записался, видно в «Записях» и в чипах на карточке события.

## Листы в таблице

Заголовки в первой строке, порядок колонок не менять — `Code.gs`
пишет строки позиционно под эти заголовки:

- **События:** `ID | Название | Тип | Дата | День недели | Время | Место | Описание`
  Тип — `Тренировка` или `Забег`. Дата — как `15.10.2026`.
  Регулярно: среда — ОФП 19:00, суббота — общий бег 10:00.
- **Объявления:** `ID | Категория | Заголовок | Автор | Текст | Дата | Статус`
- **Участники:** `ID | Имя | Фото | Год вступления | Стаж бега | Дистанции | Цель | Темп | Люблю | Группа`
- **Эстафеты:** `ID | Название | Год | Команда | Участники | Дата | Результат | Фото`
- **Записи:** `ID | Участник | Событие | Дата записи | Статус`
  Заполняется сам при записи, руками вести не нужно.

## Как вносить изменения

### Фронт (HTML/CSS/JS)

1. Правьте файлы в этой папке, проверьте `node --check script.js`.
2. Загрузите изменённые файлы в репозиторий, ветка `main`.
3. GitHub Pages обновится сам через 1–2 минуты.
   Проверьте: `curl` на `https://zhiryakov2-dotcom.github.io/run-club-mini-app/script.js`
   должен содержать новый код.

### Бэкенд (Code.gs)

1. Откройте проект «RUN CLUB — сервер приложения» в Apps Script
   (создан через Расширения → Apps Script из таблицы).
2. Замените `Code.gs` целиком новым текстом.
   **Важно:** вставка в редактор Monaco иногда не срабатывает —
   сначала выделите всё (Ctrl+A) и удалите, потом вставляйте в пустой
   редактор, затем проверьте поиском, что новый код на месте.
3. Сохраните. Сделайте **новую версию того же развёртывания**:
   Развернуть → Управление развёртываниями → изменить активное →
   Версия: «Новая версия». URL при этом сохраняется.
   Не создавайте отдельное новое развёртывание — URL поменяется,
   и его придётся менять в `script.js`.
4. Проверьте URL `/exec` в браузере: должен вернуться JSON
   `{"ok":true,"events":[...],...}`.

## Проверка без бэкенда (только вёрстка)

Запустите локально `python3 -m http.server` в этой папке и откройте
`http://localhost:8000/index.html?demo=1` — данные возьмутся из
`api-example.json`. Это проверяет только внешний вид, не таблицу.

## Если снова «Не удалось подключиться»

- URL в `script.js` точно `/exec` и начинается с `https://script.google.com/macros/s/`?
- В развёртывании стоит доступ «Все», а не «Только я»?
- После правок `Code.gs` сделано новое развёртывание (новая версия)?
- Откройте URL `/exec` просто в браузере: должен вернуться JSON
  `{"ok":true,"events":[...],...}`, а не страница входа в Google.
  Если браузер показывает вход — доступ развёртывания не «Все».
- Mini App может кэшировать старый фронт: полностью закройте
  и заново откройте Mini App в Telegram.
